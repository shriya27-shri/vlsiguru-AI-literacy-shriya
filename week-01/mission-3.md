# Mission 3: Classifying AI Systems

## 1. Classification Table

| System                   | Main Category                     | Reason                                                                                               |
| ------------------------ | --------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Calculator               | Rule-based / Traditional Software | It follows programmed mathematical operations to calculate results.                                  |
| Temperature warning rule | Rule-based / Traditional Software | It compares the temperature with a predefined threshold and gives a warning.                         |
| Spam filter              | ML-based AI                       | Many spam filters learn patterns from emails to identify likely spam, although some use rules.       |
| Document summariser      | Generative AI                     | An AI-based summariser can generate a shorter version of a document while retaining its main points. |
| Traffic ETA prediction   | ML-based AI                       | It can use traffic data and learned patterns to estimate travel time.                                |

## 2. Easy Classification

The calculator is easy to classify because it follows programmed mathematical operations. For a normal calculator, the result comes from applying defined operations to the input.

## 3. Difficult Classification

The spam filter is a more difficult classification because spam detection can use both predefined rules and machine learning. The category depends on how the particular spam filter works.

## 4. My Own Example

**Example: AI assistant for DFT learning**

An AI assistant that explains scan testing concepts and generates practice questions can be classified as Generative AI because it produces new text based on the user's prompt.

## 5. What I Learned

I learned that not every automated system uses AI. Some systems follow fixed rules, while others learn patterns from data or generate new content. The category depends on how the system actually works.
