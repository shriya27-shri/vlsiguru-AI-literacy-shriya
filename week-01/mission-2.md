# Mission 2 — AI, ML, Deep Learning and Generative AI

## 1. Artificial Intelligence (AI)

AI is the broad field of creating computer systems that can perform tasks such as reasoning, problem-solving and decision-making.

**Example:** A system that helps identify possible faults in an electronic circuit.

## 2. Machine Learning (ML)

Machine learning is a part of AI in which a computer learns patterns from data to make predictions or decisions.

**Example:** Predicting traffic conditions using historical and current traffic data.

## 3. Deep Learning (DL)

Deep learning is a part of machine learning that uses neural networks with multiple layers to learn complex patterns.

**Example:** Recognising objects in images using a trained neural network.

## 4. Generative AI (GenAI)

Generative AI produces new content, such as text, images or code, in response to a prompt.

**Example:** Google Gemini generating an explanation of a digital electronics concept.

## 5. Relationship between the concepts

AI is the broad field. Machine learning is a subset of AI, and deep learning is a subset of machine learning. Generative AI describes systems that generate content and often uses deep learning models.
