# Mission 6 — Chatbot or Agent?

## 1. Key Concepts

- **LLM:** A large language model that processes and generates language.
- **AI application:** Software that uses AI to perform tasks for users.
- **RAG:** Retrieval-Augmented Generation retrieves relevant information to support an AI-generated response.
- **Tool-using assistant:** An AI system that can use tools, such as search or a calculator, to complete a task.
- **Agent:** A system that works toward a goal through multiple steps and can use tool results to determine what to do next.

## 2. Workflow

User defines a goal → AI model interprets the request → information is retrieved or a tool is used → results are evaluated → the system responds or takes an authorised action.

An agentic workflow may repeat the tool-use and evaluation steps until it reaches its goal or needs human input.

## 3. Everyday Example: Shopping Price Comparison

When I want to buy a product, I search on Google and compare prices across sellers.

A tool-using assistant could retrieve product listings and prices. A more agentic workflow could compare several options against my budget and requirements, check the results, and present suitable choices.

## 4. What I Learned

A chatbot can generate answers, while an agentic system can take multiple steps toward a goal and use tools to make progress. RAG helps an application retrieve information, but using RAG alone does not automatically make a system an agent.

Human review remains important, especially before purchases or other actions that have real-world consequences.
