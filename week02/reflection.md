# Week 02 — Reflection

## 1. What I Understand Better Now

Through the Week 02 missions, I developed a clearer understanding of the relationship between artificial intelligence and machine learning. I learned that machine learning is an approach in which a model learns patterns from data rather than relying only on explicitly written rules.

I also understand the basic machine learning workflow more clearly: collecting and preparing data, choosing features and a target, training a model, evaluating its performance, and testing whether it generalises to unseen examples.

Another important lesson is that different problems require different approaches. Classification predicts categories, regression predicts numerical values, and clustering groups similar examples without requiring predefined labels.

The semiconductor case study helped me connect these concepts to VLSI engineering. Machine learning may help engineers predict timing risks and prioritize areas for investigation, but predictions still need to be checked using reliable engineering analysis.

## 2. What I Still Find Confusing

I would like to understand better how to select an appropriate machine learning algorithm for a particular problem and how to determine which features are most useful.

I also want more practice interpreting evaluation metrics. For example, accuracy can be misleading when one class is much more common than another. I need to become more confident in deciding when precision, recall, or an error metric is more appropriate.

Another area I want to explore is how to determine whether a model will perform well on a new chip design when its training data came from different designs or conditions.

## 3. What I Want to Learn Next

My next learning goals are:

1. Practise preparing a small dataset and identifying its features and target.
2. Build a simple classification or regression model using Python.
3. Split data into training and test sets and evaluate the model on unseen examples.
4. Compare a model against a simple baseline and understand its errors.
5. Explore how machine learning can support VLSI tasks such as timing prediction, physical design, and design verification.

## 4. Final Takeaway

My main takeaway from Week 02 is that machine learning is a useful tool for learning patterns and making predictions, but it is not automatically the best solution for every problem. Data quality, evaluation, generalisation, and human oversight all matter.

In semiconductor engineering, machine learning can support engineers by identifying possible risks earlier and helping prioritize work. However, its predictions should not replace the verification and sign-off processes needed to ensure a reliable chip design.
